# Validation caveat

The final model split keeps all candidate scenarios for the same synthetic patient together, which prevents direct patient-scenario leakage.

However, the synthetic cohort was generated by repeatedly bootstrapping the same 17 real donor trajectories. All 17 record donors and all 17 prior-history donors occur in train, validation, and test.

Therefore:

- the reported C-index / Spearman / top-1 / pairwise metrics are valid as **semi-synthetic task-recovery metrics**;
- they are **not independent validation on unseen real patients**;
- Patient_101 is a **demo case**, not an external validation case;
- the correct presentation wording is **"held-out synthetic patient instances from a shared 17-patient donor library."**

For a future clinical study, split by real donor/patient (and ultimately evaluate on an external cohort) before making generalization claims.
